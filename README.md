# eeg-adhd-honest-eval
do the published 95–99% ADHD accuracies survive a proper child-level split? The data is 61 ADHD + 60 control children
# Does EEG really detect ADHD?
Many studies report 95–99% accuracy classifying ADHD from EEG. Most split data by time window, so the same child appears in training and test. This repo re-tests those claims with child-level splits.

## Data
EEG data for ADHD/Control children (IEEE DataPort): 61 ADHD + 60 controls, ages 7–12, 19 channels, 128 Hz.
